# Учебная конфигурация 1С - Библиотека

Учебный проект, выполненный в рамках курса
по администрированию и программированию 1С
от компании «Первый Бит».

## Описание

Конфигурация предназначена для автоматизации
учета книг, читателей, выдачи и возврата книг
в библиотеке.

## Реализованные возможности

- Учет книг и их характеристик.
- Учет читателей.
- Регистрация выдачи и возврата книг.
- Хранение информации о выданных книгах
  в регистре сведений.
- Формирование отчетов о выданных книгах
  и книгах в наличии.

## Объекты конфигурации

### Справочники
- Книги
- Читатели
- Библиотекари

### Регистры накопления

- ШтрафыЗаПросрочку
- Посещаемость

### Отчеты
- СписокВыданныхКниг
- КнигиВНаличии
- Штрафы
- ГрафикПосещаемости

## Используемые технологии
- 1С:Предприятие 8.3
- Конфигуратор
- Встроенный язык 1С

## Запуск проекта

1. Создать новую информационную базу.
2. Открыть ее в режиме «Конфигуратор».
3. Выбрать «Конфигурация» → «Загрузить
   конфигурацию из файлов».
4. Указать папку Configuration.
5. Сохранить конфигурацию и обновить базу данных.
